Extend bot/handlers/broadcast.py (which already has router and /stop, /unsubscribe from Plan 01) with the broadcast FSM flow:

1. Import: Command from aiogram.filters, FSMContext from aiogram.fsm.context, Bot from aiogram, asyncio, BroadcastStates from bot.states, get_broadcast_recipients from bot.db, AppConfig from bot.config. Import TelegramForbiddenError and TelegramRetryAfter from aiogram.exceptions.

2. Add admin-only check helper (not a filter class, just inline check):
   ```python
   def _is_admin(user_id: int, config: AppConfig) -> bool:
       return user_id in config.env.admin_ids
   ```

3. `cmd_broadcast` handler — Command("broadcast"):
   - Check `_is_admin(message.from_user.id, config)`. If not admin, silently return (no response).
   - Set state to BroadcastStates.waiting_message.
   - Reply with texts.MSG_BROADCAST_PROMPT.

4. `process_broadcast_message` handler — BroadcastStates.waiting_message, F.text:
   - Store message text in FSM data: `await state.update_data(broadcast_text=message.text)`.
   - Call `get_broadcast_recipients()` to get count.
   - If count == 0, reply with texts.MSG_BROADCAST_NO_RECIPIENTS, clear state, return.
   - Store count in FSM data: `await state.update_data(recipient_count=count)`.
   - Set state to BroadcastStates.waiting_confirm.
   - Reply with texts.MSG_BROADCAST_CONFIRM.format(count=count).

5. `process_broadcast_confirm` handler — BroadcastStates.waiting_confirm, F.text:
   - If message.text.lower().strip() not in ("так", "yes", "да"): reply with texts.MSG_BROADCAST_CANCELLED, clear state, return.
   - Get FSM data (broadcast_text).
   - Clear state immediately.
   - Reply with texts.MSG_BROADCAST_STARTED.
   - Call get_broadcast_recipients() again (fresh list at send time).
   - Send loop with rate limiting:
     ```python
     sent = failed = blocked = 0
     for chat_id in recipients:
         try:
             await bot.send_message(chat_id, broadcast_text)
             sent += 1
         except TelegramForbiddenError:
             blocked += 1
         except TelegramRetryAfter as e:
             await asyncio.sleep(e.retry_after)
             try:
                 await bot.send_message(chat_id, broadcast_text)
                 sent += 1
             except Exception:
                 failed += 1
         except Exception:
             failed += 1
         await asyncio.sleep(0.05)  # 20 msg/sec rate limit
     ```
   - Reply with texts.MSG_BROADCAST_COMPLETE.format(sent=sent, failed=failed, blocked=blocked).

6. The bot parameter is injected by aiogram automatically when declared in handler signature. The handler for confirm needs `bot: Bot` as a parameter.

Note: Text-only broadcast for v1 (per research decision). The F.text filter on waiting_message means non-text messages are ignored (admin must send text).
