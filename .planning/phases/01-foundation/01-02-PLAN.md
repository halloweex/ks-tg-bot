Create `bot/db.py` with async SQLite initialization and connection management using aiosqlite.

**DB_PATH**: `Path("bot_data.db")` — file created in project root.

**Schema (two tables for Phase 1):**

```sql
CREATE TABLE IF NOT EXISTS users (
    chat_id    INTEGER PRIMARY KEY,
    phone      TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS opt_out (
    chat_id      INTEGER PRIMARY KEY,
    opted_out_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

**Functions:**

1. `async def init_db() -> None`:
   - Opens connection via `async with aiosqlite.connect(DB_PATH) as db:`
   - Executes both CREATE TABLE statements
   - Calls `await db.commit()`
   - Logs success via loguru: `logger.info("Database initialized at {}", DB_PATH)`
   - Safe to call multiple times (IF NOT EXISTS)

2. `async def get_db() -> aiosqlite.Connection`:
   - Returns `await aiosqlite.connect(DB_PATH)`
   - Caller is responsible for closing (use as context manager)
   - Docstring: "Open a connection. Caller must close it (use as async context manager)."

**Important patterns:**
- Do NOT create a module-level shared connection (causes "cannot reuse" errors)
- Every operation opens and closes its own connection via `async with`
- Import aiosqlite, Path from pathlib, logger from loguru

<task type="auto">
  <name>Task 2: Create KeyCRM REST API client with phone normalization</name>
  <files>bot/services/keycrm.py</files>
  <action>
Create `bot/services/keycrm.py` — async httpx client for KeyCRM REST API.

**CRITICAL finding from live API testing:** KeyCRM stores phones in mixed formats — some `380XXXXXXXXX` (no plus), some `+380XXXXXXXXX`. The `filter[buyer_phone]` does EXACT match. Always strip the `+` prefix before querying.

**Phone normalization function:**
```python
def normalize_phone_for_keycrm(phone: str) -> str:
    """Strip +, spaces, dashes, parens. '``+380671234567``' -> '``380671234567``'"""
    return phone.replace("+", "").replace(" ", "").replace("-", "").replace("(", "").replace(")", "")
```

**KeyCRMOrder dataclass:**
- `id: int`
- `status_name: str` (from nested status.name, default "unknown")
- `grand_total: float` (UAH amount)
- `ordered_at: str` (ISO timestamp)
- `products: list[dict]` (each dict: {"name": str, "qty": int})
- `buyer_name: str` (from nested buyer.full_name)
- `payment_status: str` (e.g., "paid", "not_paid")

**KeyCRMClient class:**
- `__init__(self, api_key: str)`: Store headers dict `{"Authorization": f"Bearer {api_key}", "Accept": "application/json"}`
- `BASE_URL = "https://openapi.keycrm.app/v1"` (module-level constant)

- `async def get_orders_by_phone(self, phone: str) -> list[KeyCRMOrder]`:
  - Normalize phone via `normalize_phone_for_keycrm(phone)`
  - Query: `GET /v1/order` with params:
    - `include`: `buyer,products,status`
    - `filter[buyer_phone]`: normalized phone (no + prefix!)
    - `limit`: 50
  - Use `async with httpx.AsyncClient() as client:` (new client per request — correct for this scale)
  - Timeout: 10.0 seconds
  - On success: parse each order in `data["data"]` list via `_parse_order()`
  - On `httpx.HTTPError`: log error with loguru, return empty list (never crash)

- `_parse_order(raw: dict) -> KeyCRMOrder` (module-level helper):
  - Extract nested fields safely with `.get()` and default values
  - Products: `[{"name": p["name"], "qty": p["quantity"]} for p in raw.get("products", [])]`
  - Status: `raw.get("status", {}).get("name", "unknown")`
  - Buyer: `raw.get("buyer", {}).get("full_name", "")`

**Rate limit note (60 req/min):** No throttling needed at this scale — bot serves one user at a time. Log a warning if 429 status is received.

Create `bot/services/shopify.py` — async httpx client for Shopify GraphQL Admin API.

**Critical context:** The Shopify Custom App does NOT exist yet. `shopify_api_token` will be None at startup. The bot must run without Shopify. The entry point (Plan 03) checks `if config.env.shopify_api_token:` before creating the client — if None, `dp["shopify"] = None` and handlers skip Shopify lookups.

**GraphQL query** (module-level constant `GRAPHQL_QUERY`):
```graphql
query GetCustomerByPhone($phone: String!) {
  customers(first: 1, query: $phone) {
    edges {
      node {
        id
        displayName
        orders(first: 50, sortKey: CREATED_AT, reverse: true) {
          edges {
            node {
              id
              name
              displayFinancialStatus
              displayFulfillmentStatus
              totalPriceSet {
                shopMoney { amount currencyCode }
              }
              createdAt
              lineItems(first: 10) {
                edges {
                  node { name quantity }
                }
              }
            }
          }
        }
      }
    }
  }
}
```

**ShopifyOrder dataclass:**
- `id: str`
- `name: str` (e.g., "#1001")
- `financial_status: str`
- `fulfillment_status: str`
- `total_price: str`
- `currency: str`
- `created_at: str`
- `line_items: list[dict]` (each dict: {"name": str, "qty": int})

**ShopifyClient class:**
- `__init__(self, store_url: str, api_token: str)`:
  - Build endpoint: `f"https://{store_url}/admin/api/2025-01/graphql.json"`
  - Store headers: `{"X-Shopify-Access-Token": api_token, "Content-Type": "application/json"}`

- `async def get_orders_by_phone(self, phone: str) -> list[ShopifyOrder]`:
  - Phone format for Shopify: WITH `+` prefix (opposite of KeyCRM!)
  - Variable: `{"phone": f"phone:{phone}"}` — Shopify query syntax requires `phone:` prefix
  - POST to GraphQL endpoint with `json={"query": GRAPHQL_QUERY, "variables": variables}`
  - Timeout: 10.0 seconds
  - Parse: `data["data"]["customers"]["edges"]` → first customer → `orders["edges"]`
  - If no customers found: return empty list
  - On `httpx.HTTPError`: log error, return empty list
  - Also check for GraphQL errors in response: `if "errors" in data: log and return []`

- `_parse_shopify_order(node: dict) -> ShopifyOrder` (module-level helper):
  - Extract `totalPriceSet.shopMoney.amount` and `.currencyCode`
  - Line items: flatten `edges` → `[{"name": e["node"]["name"], "qty": e["node"]["quantity"]}]`

**Do NOT install ShopifyAPI PyPI package.** Shopify deprecated REST for new apps. GraphQL via httpx is the correct approach (and only ~50 lines of code).
