Create `bot/__main__.py` — the entry point for `python -m bot`.

**Structure:**

```python
import asyncio
from aiogram import Bot, Dispatcher
from aiogram.client.default import DefaultBotProperties
from aiogram.enums import ParseMode
from loguru import logger
```

**`async def main()` function:**

1. **Load config:**
   ```python
   config = load_config()
   logger.info("Config loaded. Brand: {}", config.brand_name)
   ```

2. **Create Bot instance:**
   ```python
   bot = Bot(
       token=config.env.bot_token,
       default=DefaultBotProperties(parse_mode=ParseMode.HTML),
   )
   ```

3. **Create Dispatcher:**
   ```python
   dp = Dispatcher()
   ```

4. **Dependency injection via dp workflow_data:**
   ```python
   dp["config"] = config
   dp["keycrm"] = KeyCRMClient(api_key=config.env.keycrm_api_key)
   ```

5. **Conditional Shopify client (graceful degradation):**
   ```python
   if config.env.shopify_api_token and config.env.shopify_store_url:
       dp["shopify"] = ShopifyClient(
           store_url=config.env.shopify_store_url,
           api_token=config.env.shopify_api_token,
       )
       logger.info("Shopify client initialized")
   else:
       dp["shopify"] = None
       logger.warning("Shopify credentials not configured — running in KeyCRM-only mode")
   ```

6. **Startup hook (database initialization):**
   ```python
   @dp.startup()
   async def on_startup() -> None:
       await init_db()
       logger.info("Bot started successfully")
   ```

7. **Include routers:**
   ```python
   dp.include_router(common_router)
   ```

8. **Start polling:**
   ```python
   logger.info("Starting polling...")
   await dp.start_polling(bot)
   ```

**Bottom guard:**
```python
if __name__ == "__main__":
    asyncio.run(main())
```

**Imports:**
- `from bot.config import load_config`
- `from bot.db import init_db`
- `from bot.handlers.common import router as common_router`
- `from bot.services.keycrm import KeyCRMClient`
- `from bot.services.shopify import ShopifyClient`

Do NOT use `aiogram.executor.start_polling` — that is aiogram 2.x pattern. Use `await dp.start_polling(bot)` which is aiogram 3.x.

Create `bot/handlers/common.py` — the /start command handler.

**Structure:**

```python
from aiogram import Router
from aiogram.filters import CommandStart
from aiogram.types import Message

from bot.config import AppConfig
from bot import texts

router = Router()
```

**Handler:**
```python
@router.message(CommandStart())
async def cmd_start(message: Message, config: AppConfig) -> None:
    """Handle /start command — send branded greeting."""
    greeting = texts.GREETING.format(brand_name=config.brand_name)
    await message.answer(greeting)
```

**Key points:**
- Use `CommandStart()` filter from aiogram 3 (not `commands=["start"]` — that is aiogram 2)
- The `config` parameter is automatically injected by aiogram's DI system because `dp["config"] = config` was set in __main__.py
- The greeting uses `texts.GREETING.format(brand_name=...)` — NO hardcoded Ukrainian strings in this file
- Module-level `router = Router()` — this is the aiogram 3 pattern for modular handlers
- The router is included in the dispatcher via `dp.include_router(common_router)` in __main__.py

This handler is minimal for Phase 1. Phase 2 will add phone collection and validation. Phase 3 will add menu navigation. For now, /start just shows the greeting.
