2. Create `bot/handlers/orders.py` with a Router and the following:

   a) Helper function `_format_keycrm_order(order: KeyCRMOrder) -> str`:
      Format a single KeyCRM order as an HTML string block:
      ```
      📦 Замовлення (📸 Instagram)
      Статус: {order.status_name}
      Товари: {comma-joined product names with qty}
      Сума: {order.grand_total} грн
      Дата: {formatted date from order.ordered_at}
      ```
      Parse `ordered_at` with `datetime.fromisoformat()`. Format date as `DD.MM.YYYY`. Handle parse errors gracefully (show raw string if parsing fails). Product list: join as "ProductName x qty" comma-separated.

   b) Helper function `_format_shopify_order(order: ShopifyOrder) -> str`:
      Format a single Shopify order similarly:
      ```
      📦 Замовлення {order.name} (🌐 Сайт)
      Статус: {order.fulfillment_status or order.financial_status}
      Товари: {comma-joined product names with qty}
      Сума: {order.total_price} {order.currency}
      Дата: {formatted date from order.created_at}
      ```
      Parse `created_at` with `datetime.fromisoformat()`. Format date as `DD.MM.YYYY`.

   c) Helper function `_format_all_orders(keycrm_result, shopify_result) -> str`:
      - Takes the raw results from asyncio.gather (may be lists or Exceptions).
      - Build a list of `(date_str, formatted_text)` tuples.
      - For KeyCRM orders (if not Exception): format each with _format_keycrm_order, use ordered_at as sort key.
      - For Shopify orders (if not Exception): format each with _format_shopify_order, use created_at as sort key.
      - Sort combined list by date descending.
      - Check if both results are Exceptions — if so, return `texts.ERR_API_UNAVAILABLE`.
      - If combined list is empty (no orders from either source), return `texts.MSG_NO_ORDERS`.
      - If total formatted text exceeds 3800 chars (leaving margin for header), truncate to first N orders that fit and append "\n\n...та інші замовлення" (and other orders).
      - Return header + joined formatted orders.

   d) Callback handler `show_orders` — triggered by `MenuAction.filter(F.action == "orders")`:
      - `await callback.answer()` FIRST.
      - Get phone from DB: `phone = await get_user_phone(callback.from_user.id)`.
      - If no phone, `edit_text` with `ERR_PHONE_NOT_FOUND` + back to main menu button. Return.
      - Show loading: `await callback.message.edit_text(texts.MSG_ORDERS_LOADING)`.
      - Fetch orders in parallel using `asyncio.gather` with `return_exceptions=True`:
        - Always include `keycrm.get_orders_by_phone(phone)`.
        - Include `shopify.get_orders_by_phone(phone)` only if `shopify is not None`. Otherwise use a coroutine that returns `[]`.
      - Format results with `_format_all_orders`.
      - Build a back-to-menu keyboard: single button with `MenuAction(action="back")` text `BTN_BACK`.
      - `await callback.message.edit_text(formatted_text, reply_markup=back_kb, parse_mode=None)`.
        Use `parse_mode=None` to avoid HTML parsing issues with order data. If the order text contains special chars, this prevents crashes.
      - Wrap the edit_text in try/except for `TelegramBadRequest` — if caught, send new message instead.

   DI parameters for the handler: `callback: CallbackQuery`, `callback_data: MenuAction`, `keycrm: KeyCRMClient`, `shopify: ShopifyClient | None`, `config: AppConfig`.
